# Changelog

## 0.0.1-Demo-final — 2026-08-27

Archived public snapshot of work completed through 2026-08-13.

- Added a shared NPC casting session used by all four demo spell routes.
- Added fireball, frost blizzard, aqua bubble beam, and terra earthquake adapters.
- Added configurable CustomNPCs ECMAScript examples with automatic remembered-target casting.
- Added the initial visual skill-block editor, bounded loops, choice-based parameters, validation, and NPC binding.
- Added unit and contract coverage for bridge, route, script, layout, choice, and loop behavior.
- Changed project licensing from private/ARR metadata to `GPL-3.0-only` for this public snapshot.
- Marked the project archived and unsupported.
