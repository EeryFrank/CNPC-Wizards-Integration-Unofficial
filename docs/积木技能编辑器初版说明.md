# 积木技能编辑器初版说明

## 初版定位

本版是“顺序积木链＋有限循环”原型：玩家组合触发、目标、条件、法术、等待、循环、基础能力、动作和特效块，服务端按连接顺序执行。它不会生成任意 Java/ECMAScript，也不是完整的分支图；调用 Wizards/Spell Engine 的已有技能时，仍进入项目现有统一施法桥接层。

## 打开、编辑和绑定

1. 客户端和服务端都安装同版本模组及项目所用的 CustomNPCs 非官方版，进入服务器。
2. 用 NPC 魔杖打开一个 NPC 的编辑界面，在顶部“全局设置”和“删除”之间点击新增的“编程技能”标签。标签会直接携带当前正在编辑的 NPC；不需要退出后用准星重选。
3. 用右侧“＋已有法术 / ＋条件（选择） / ＋流程（选择） / ＋能力（选择） / ＋动作（选择） / ＋特效（选择）”添加积木。类别按钮会打开中文选择页，点选后才加入，不再通过隐藏轮换决定类型。
4. 左侧选择积木，在右侧修改参数，点击“参数应用”；法术、目标方式、状态效果、粒子、声音和循环次数使用选择页，倍率、冷却、数量等数值仍可填写。可上移、下移、删除和翻页。
5. 点击“保存本地”保存草稿。默认路径为客户端实例的 `config/cnpc_wizards_integration/skill_block_draft.json`。
6. 点击“保存并绑定当前 NPC”。关闭积木页会返回之前的 CustomNPCs NPC 编辑页。
7. 绑定需要权限等级 2（OP），并要求玩家仍在 NPC 12 格内。聊天栏显示服务端验证及保存结果。服务端方案路径为 `config/cnpc_wizards_integration/skill_block_programs.json`。
8. 当前触发器是“受到攻击时”：被绑定实体受到一个有效 LivingEntity 攻击后，执行整条积木链。

## 当前积木库

| 分类 | 积木 | 主要参数 |
|---|---|---|
| 触发 | 受到攻击时 | 无；必须放在第一块 |
| 目标 | 锁定攻击者 | 无 |
| 条件 | 目标距离、目标可见 | `max_distance` |
| 法术 | 调用已有法术 | `spell_id`、`target_strategy`、功率/伤害/治疗倍率、`cooldown_ticks` |
| 流程 | 等待、循环开始/循环结束、结束 | `ticks`、`repeat_count`；添加循环时自动生成一对边界，结束必须放在最后 |
| 能力 | 治疗自己、治疗目标、直接伤害、击退、拉近、点燃、熄灭、状态效果 | `amount`、`strength`、`seconds`、效果 ID/时长/等级 |
| 动作 | 主手挥动、副手挥动、受击动作 | 无 |
| 特效 | 粒子爆发、粒子圆环、播放声音 | 粒子/声音 ID、数量、速度、半径、音量、音调 |

已有法术示例：

- `wizards:fireball`，`target_strategy=direct`，建议冷却 `60` tick。
- `elemental_wizards_rpg:aqua_bubble_beam`，`target_strategy=direct`，建议冷却 `300` tick。
- `wizards:frost_blizzard`，`target_strategy=direct`，建议冷却 `320` tick。
- `elemental_wizards_rpg:terra_earthquake`，`target_strategy=none`，建议冷却 `700` tick。

20 tick 约等于 1 秒。普通法术参数不写入 Java 技能实现；积木将法术 ID 和配置交给统一桥接层。

## 服务端安全边界

- 每条方案最多 32 块，等待块最多 8 个；等待单块不超过 1,200 tick。
- 循环次数只能为 2–16，最多嵌套 3 层；循环展开后最多 256 步、累计等待最多 12,000 tick。运行时另有每程序每 tick 64 步及全服每 tick 2,048 步硬预算。
- 直接伤害或治疗单块不超过 40，击退/拉近强度不超过 3，点燃不超过 10 秒。
- 状态效果最长 1,200 tick、最高等级参数 4；粒子单块最多 100。
- 粒子和声音 ID 使用初版白名单；法术倍率不超过 10。
- 客户端本地验证不能替代服务端验证；网络传入的数据会重新解析、重新校验。
- 同一实体已有积木链运行时，不重复启动第二条；受击只排队到下一服务器 tick 执行，避免同步伤害连锁递归。
- 法术调用若被统一桥接层拒绝（例如冷却、施法忙、目标无效），本次链在该法术块结束，不伪造后续成功表现。

## 初版已知边界

- 支持从上到下的单链连接和固定次数循环；不支持条件分叉、无限循环、变量、数学表达式或任意脚本块。
- 仅提供“受到攻击时”触发器；巡逻、定时、低血量、看见目标等触发器属于后续扩展。
- “编程技能”标签是对开发时使用的 `CustomNPCs-Unofficial-Fabric-1.21.1.20260521.jar` 的可选客户端兼容注入；该第三方 JAR 不随本仓库分发。未安装兼容 CustomNPCs 版本时不显示标签，但本模组服务端基础入口仍可加载。
- “动作”目前使用原版实体挥手/受击广播；第三方 CustomNPCs 自定义动画轨道需要单独适配。
- 基础能力是本模组提供的通用 Minecraft 行为；Wizards 具体法术的弹道、动画和法术效果仍由第三方模组及统一桥接层负责。

## 游戏内人工验收

以下结果必须在真实客户端画面中确认，自动构建不能代替：

1. NPC 编辑界面顶部指定位置显示“编程技能”标签；点击后携带正确 NPC 打开页面，说明文字清晰，积木、连接线、参数区及选择页在当前分辨率下可操作。
2. 保存后重开界面能读取草稿；管理员能将有效方案绑定到准星目标，非管理员会被拒绝。
3. 绑定 NPC 受击后，条件、等待、循环次数、基础能力和顺序执行符合配置。
4. 火球等法术块确实进入统一桥接 trace；冷却拒绝时链停止。
5. 主/副手挥动、受击动作、粒子爆发/圆环、声音、伤害、治疗、击退、拉近、点燃和状态效果的实际观感可接受。
6. 服务端重启后绑定仍存在；非法超限方案不会写入服务端配置。

上述游戏表现当前统一标记为 `NEEDS_MANUAL_VALIDATION`。
